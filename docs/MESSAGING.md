# Messaging excluded

Version 0.4.1/build 5 contains no SMS architecture, transport interface, provider SDK, endpoint configuration, SMS settings, or delivery action. The former disabled messaging interface and its obsolete tests were removed from this release.

Payment submission records only a local simulation. No real money moves and no notifications or SMS messages are sent. Runtime names and recipients remain on the device. The local payment flow, account snapshots, persistence and bundle identifier are unchanged.
