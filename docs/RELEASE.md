Independent banking hackathon demonstration using fictional data only. Not affiliated with Chase or Zelle. All transfers, activity, QR scanning, and Siri actions are local simulations.

Download BankingHackathonDemo-unsigned.ipa. This is an unsigned ARM64 physical iPhone build for iOS 17 or later. AltStore Classic must sign it during sideloading. It is not directly installable by tapping the file.

The source build passed payment model tests and iPhone simulator UI tests. The IPA verification checks archive structure, metadata, ARM64 architecture, and the physical iOS Mach-O platform. Installation on a real iPhone remains to be tested by the recipient.

See the README for Windows and AltStore instructions. Apple sign in happens only through your local AltStore or AltServer installation. No Apple credentials belong in GitHub or this app.
