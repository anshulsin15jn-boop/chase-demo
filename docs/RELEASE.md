Chase Demo 0.2.0 is an independent hackathon simulation, not affiliated with Chase or Zelle. All payments, notifications and external services are simulated.

This update adds first-name onboarding saved locally, personalized checking and savings labels, actual local Today defaults, automatic cents entry, inline amount validation, corrected vector icons and spacing, flexible local recipient creation, and the supplied app icon. Existing recipients and activity are retained during onboarding. The bundle identifier is unchanged.

Download ChaseDemo-unsigned.ipa. This is an unsigned ARM64 physical-iPhone build for iOS 17 or later. It requires signing through local AltStore Classic/AltServer or Sideloadly. Use the same signing account and app identity, and install over the existing app without deleting it to retain local data.

The publication workflow requires a successful verified build. See the repository's version 0.2 verification report for actual test results, screenshot comparison and artifact metadata. Real iPhone installation and update data preservation remain untested.

No private comparison screenshots or user-entered runtime data are included. Apple credentials are never requested by the app or CI.
