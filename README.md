# Banking Hackathon Demo

Native SwiftUI banking simulation for a hackathon. Project setup is in progress.

The app will use fictional demonstration data only. All payments and recipient actions will be local simulations. No banking connections or Apple credentials belong in this project.

Private visual references must remain outside this repository and must never be committed, uploaded, or bundled. Reference inspection is pending because the supplied local reference folder is unavailable.

No app implementation or IPA has been produced yet.
